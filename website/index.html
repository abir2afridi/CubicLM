Why CubicLM

Everything you need.
Nothing you don't.

A fast, beautiful chat experience with local reasoning, code execution, web search and a whole ecosystem — without the cloud tax.

🔒

Local-first & private

Your chats never leave the device in Local mode. No account, no tracking.

Any model, any provider

GGUF/LiteRT locally, plus 18 cloud providers (OpenAI, Anthropic, Gemini, Groq…).

On-device image gen

Stable Diffusion via FFI — generate images offline with Vulkan/OpenCL acceleration.

Code & tools

Syntax-highlighted code blocks, file attachments, and a sandboxed code runner.

Web-aware answers

Optional web fetch augments responses with fresh sources, cited inline.

Skills & MCP

Extend CubicLM with skills and Model Context Protocol tools — your own ecosystem.
